# VitePress
> Vite & Vue Powered Static Site Generator

## Installation
```bash
git checkout vitepress
```
```bash
npm install && npm run link:docs
```

## Start Vitepress
```bash
npm run docs:dev
```

## What it does?
- Allows you to write your docs in markdown in a seperate folder from [vitepress](https://vitepress.dev/guide/what-is-vitepress)
- Links the [vitepress](https://vitepress.dev/guide/custom-theme) inside `/docs/.vitepress`
